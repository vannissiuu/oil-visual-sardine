# 角色身份锁定参考

本文件是 oil-visual-sardine 的身份一致性补充，只约束角色是否为同一个角色；方向定义、canonical 路由和非对称拓扑同步见 [direction-lock.md](./direction-lock.md)，固定角色色号见 [color-lock.md](./color-lock.md)。不改变 Mode A / Mode B 的文字、键色、抠图、输出格式或质量流程。

## 硬规则：canonical asset 优先

两张通用 asset 仅保留为兼容入口和身份索引：

- assets/sadin-character.png：沙丁
- assets/small-wave-character.png：小浪花

任何角色场景都要先确定身体方向，再按 [direction-lock.md](./direction-lock.md) 选择对应的 facing canonical，并将其作为该方向的图像参考；不能让通用 asset 覆盖方向路由。

凡是输出含有对应角色，必须先用 view_image 加载并查看所需 asset，再把它作为图像参考或编辑输入。文字锚点只能辅助说明，不能替代视觉输入；禁止只凭文字重新绘制角色。

使用 built-in image generation 时，只替换原流程中的角色输入方式，不增加或重排 Mode A / Mode B 步骤：

1. 先对所需 canonical asset 执行 view_image。
2. 在原有图像生成调用中把所需 asset 作为角色参考图或编辑输入；工具支持 identity-preserve / compositing / edit 时使用相应能力。
3. 如果工具不能接收参考图，立即停止角色生成，改用透明 canonical PNG 做确定性合成；不能降级为文字生成，也不能接受“看起来像同类对象”的替代角色。

## 方向一致性

- 方向指身体整体的前进朝向，不指视线；眼睛、脸部朝向、四肢姿势或手持物不能单独决定方向。
- 生成前必须按 [direction-lock.md](./direction-lock.md) 选择匹配的方向 canonical。沙丁尾部永远与身体前进方向相反，所有非对称结构整体同步；小浪花的卷头、泡沫、内腔和缺口整体同步。
- 禁止只转脸、只移尾，或只局部翻转鳍、卷头、泡沫、内腔、缺口等结构；方向变更必须替换匹配 canonical，或对完整角色整体同步变换后再与目标 canonical 比对。

## 不可变身份锚点

### 沙丁

- 竖向长椭圆／种子形主体。
- 大面积奶油色腹部。
- 海雾蓝纵向结构。
- 顶部双层鳍形轮廓。
- 标志性胸鳍、尾鳍及其他非对称结构共同构成整体结构组；随所选方向 canonical 同步。
- 点眼、弧形微笑、细黑四肢。
- 黑色粗细变化墨线与圆形半调。

### 小浪花

- 低矮、宽底的浪体。
- 单侧卷头、米白泡沫帽／独立泡沫珠、内侧海雾蓝浪腔和浪峰缺口共同构成整体非对称结构组；随所选方向 canonical 同步。
- 下部暖黄／米白主体。
- 点眼、弧形微笑、细黑四肢。
- 黑色墨线与圆形半调。

锚点的位置关系、主体轮廓和主要色块拓扑共同构成身份；不能只保留脸部或颜色而改变其余结构。

## 变化边界

允许变化：四肢姿势、手持物、轻微倾斜、场景遮挡。

不允许变化：主体轮廓比例、脸部布局、主要色块拓扑、沙丁的标志性鳍、小浪花的标志性浪峰／浪峰缺口／泡沫珠。遮挡也不能制造新的轮廓、鳍、浪峰或脸部。

## 双角色比例

- 沙丁是主角，小浪花是配角；两者同框时必须一眼看出这一层级。
- 已确认的标准比例是小浪花为沙丁可见高度的 `39.2%`；普通同平面场景以 `38–42%` 为验收区间。50% 是不可超过的绝对上限。
- 小浪花的自然轮廓较宽；如果横向体量使其显得与沙丁同等醒目，需进一步缩小，确保总视觉重量仍低于沙丁。
- 透视、动作和遮挡可造成轻微比例浮动，但不得破坏“沙丁更大、小浪花更小”的主配关系。
- 39.2% 是交付验收目标，不是对生成器精确缩放能力的承诺；任何落在验收区间外的结果都只能标为草稿或未通过，不能因视觉上“差不多”而视作定稿。

### 比例生成预算

- 首次生成前就在提示词中把沙丁可见高度定义为 `100` 单位、小浪花定义为 `39.2` 单位，并要求两者处于同一地面基线；不要先随意生成再靠多轮试错找比例。
- 首图只因比例不合格时，测量渲染后的可见高度比 `r = 小浪花高度 / 沙丁高度`，计算唯一修正系数 `f = 0.392 / r`。只允许追加一次定向编辑：小浪花全身及其卷头、泡沫、内腔、缺口、脸和四肢一起等比缩放 `f`，脚底仍落在原基线；其他画面不变。
- 禁止第二次及后续“只为比例”调用图像生成器。一次修正后仍未进入 38–42% 时，若角色可分离则使用确定性缩放／合成；否则停止并如实报告，不得未经用户同意继续消耗生成次数。
- 身份、方向或内容本身错误不属于“比例修正”，应按对应规则处理；不得把多个错误伪装成比例微调。

## 验收 checklist

- [ ] 已为每个所需角色用 view_image 查看对应 canonical asset。
- [ ] 已按 [direction-lock.md](./direction-lock.md) 核对身体朝向与方向 canonical；方向不是按视线判断，且没有只转脸或只移尾。
- [ ] canonical asset 已作为图像参考或编辑输入；没有只凭文字生成。
- [ ] 沙丁仍具备完整方向无关身份锚点：种子形比例、奶油腹部、海雾蓝纵向结构、顶部双层鳍、标志性胸鳍、尾鳍及其他非对称结构组、固定脸与细肢、粗细变化墨线／圆形半调；非对称结构随所选方向 canonical 同步。
- [ ] 小浪花仍具备完整方向无关身份锚点：低矮宽底、单侧卷头、米白泡沫帽／独立泡沫珠、内侧海雾蓝浪腔、暖黄／米白下部、浪峰缺口、固定脸与细肢及墨线／圆形半调；卷头、泡沫、内腔和缺口作为整体非对称结构组随所选方向 canonical 同步。
- [ ] 两者同框且处于普通同平面场景时，小浪花目标为沙丁可见高度的 39.2%，实测处于 38–42%；绝不超过 50%，且没有因横向宽度获得足以与沙丁竞争的视觉重量。
- [ ] 比例若需要修正，只使用了测量所得的 `f = 0.392 / r` 做一次定向编辑；没有第二次比例专用生成调用。
- [ ] 只发生了允许的姿势、手持物、轻微倾斜或场景遮挡变化。
- [ ] 输出与所用 canonical asset 在原尺寸下并排检查，轮廓比例、脸部布局和主要色块拓扑相同。
- [ ] 角色被识别为同一身份，而不是普通黄色鱼、普通蓝浪或其他“同类对象”。若只是同类对象，必须拒绝，不得交付。
- [ ] 若无法提供参考图，已停止角色生成并改用透明 canonical PNG 的确定性合成。
- [ ] Mode A / Mode B 的文字、键色、抠图、输出格式和质量流程均未被改动。

## 一次定向重试模板

~~~text
定向身份修复：使用所附 canonical asset 作为 identity-preserve / edit 输入：
- <角色>：<canonical asset 路径>

保持场景、构图、动作、道具、遮挡、颜色语义、文字以及所有已正确的内容不变。
仅把 <角色> 的 <错误锚点> 修正为与 canonical asset 完全一致：
<精确描述需要恢复的锚点，例如“沙丁的尾鳍、标志性胸鳍和海雾蓝纵向结构，按所选方向 canonical 整体同步”>

必须保留该角色的主体轮廓比例、脸部布局、主要色块拓扑、标志性鳍／浪峰／泡沫珠、黑色粗细变化墨线和圆形半调。
不得把角色改成普通同类对象，不得只按文字重画，不得新增或删除其他元素。
若本次工具不能接收上述参考图，停止生成，改用透明 canonical PNG 做确定性合成。
~~~
