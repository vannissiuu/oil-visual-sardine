# 固定角色配色锁定参考

本文件是「沙丁」与「小浪花」固定身份色的唯一色号来源。色号来自现役 canonical PNG 的高透明度像素采样与语义归并，不是上游 `oil-visual` 原有硬编码值。

## 核心色票

| Token | 色号 | 用途 |
| --- | --- | --- |
| Sardine Yellow | `#FDD86F` | 沙丁主身体与暖黄主体面 |
| Sardine Mustard | `#F5BB40` | 暗部、鳍片层次与受控强调 |
| Sardine Cream | `#FCF4E4` | 腹部、泡沫与米白亮面 |
| Sardine Mist Blue | `#9ABCC2` | 海雾蓝纵向结构、浪腔与少量辅助面 |
| Sardine Ink | `#151515` | 主轮廓、脸部与线条四肢 |
| Sardine Sand | `#E9D7A4` | 沙色半调与纸面辅助色 |

## 使用规则

- 上表色号是角色身份的设计中心值；生成图中的纸纹、半调、阴影与抗锯齿允许围绕中心值产生轻微像素波动，不得把这些波动登记成新的品牌色。
- 沙丁暖黄的 canonical 采样范围约为 `#FCD361–#FEE08A`；较深暖黄约为 `#E8A62D–#FBC74B`；海雾蓝约为 `#97B5B9–#B2CACC`。这些范围只用于验收纹理与光照漂移，不替代核心色票。
- 保持低饱和、温暖、克制。禁止高饱和黄、荧光色、金属质感、玻璃质感和强渐变。
- 固定角色的主色拓扑不得随场景语义色改变。场景仍可按 `SKILL.md` 使用最多两种低饱和语义色，但不能覆盖或重定义角色身份色。
- 颜色相近但主体轮廓、脸部布局、鳍／浪峰或主要色块拓扑不同，仍判定为身份不合格；配色锁不能替代角色锁和方向锁。

## 验收

- [ ] 主暖黄、奶油色、海雾蓝与墨线中心值接近上表，整体仍为低饱和暖调。
- [ ] 纹理变化来自半调、纸纹、阴影或抗锯齿，而非新增无依据色块。
- [ ] 海雾蓝只占少量辅助面积，没有压过暖黄与奶油色主体。
- [ ] 场景语义色没有污染角色固定色块。
