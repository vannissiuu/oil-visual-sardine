# 角色方向与拓扑锁定参考

本文件只补充沙丁与小浪花的左右方向路由和非对称结构约束。它不替换身份锁，也不改变 Mode A / Mode B、输出路径、键色、抠图、文字或既有质量检查流程；完成本文件的角色核验后，继续原有生产流程。

## 方向定义

- “向左/向右”指角色身体整体的前进朝向，以身体轴线、主体轮廓和尾部／浪峰的相对关系判断，不以眼睛、脸部朝向、四肢姿势或手持物的指向判断。
- 生成前先确定每个角色的身体朝向，再从下表选择匹配的方向 canonical。`facing-left` 与 `facing-right` 是身体方向路由，不是视线标签。
- `assets/sadin-character.png` 与 `assets/small-wave-character.png` 继续作为通用身份锚点；画面有明确左右身体方向时，必须优先使用下表对应的方向 canonical，不能用默认方向猜测或事后局部修补。

## 四个 canonical 路由

| 角色 | 身体朝向 | 必选 canonical | 路由锚点 |
| --- | --- | --- | --- |
| 沙丁 | 向左 | `assets/sadin-facing-left.png` | 现有定妆照方向；尾在画面右 |
| 沙丁 | 向右 | `assets/sadin-facing-right.png` | 尾在画面左 |
| 小浪花 | 向右 | `assets/small-wave-facing-right.png` | 现有定妆照卷头与泡沫在画面右 |
| 小浪花 | 向左 | `assets/small-wave-facing-left.png` | 卷头与泡沫在画面左 |

四个路径都是方向 canonical。若目标方向的文件不可用，应暂停该角色的生成并补齐或改用可核验的确定性合成；不得退回只凭文字生成，也不得把另一方向的文件当作目标方向。

## 拓扑约束与禁止变换

### 沙丁

- 尾部永远位于身体前进方向的反侧：向左时尾在画面右，向右时尾在画面左。
- 尾鳍、顶部双层鳍、海雾蓝纵向结构、胸鳍、切口／偏移及其他非对称色块和轮廓必须随身体方向整体同步；不能保留一半左向拓扑再拼接另一半右向结构。

### 小浪花

- 卷头、泡沫帽／独立泡沫珠、内侧海雾蓝浪腔和浪峰缺口必须作为一个非对称结构组整体同步。
- 不能只移动卷头或泡沫，不能只翻转内腔或缺口，也不能让身体朝向与这组标志性结构指向相反。

### 通用禁止项

- 禁止只转脸、只转眼睛、只移尾，或只局部翻转鳍、卷头、泡沫、内腔、缺口。
- 方向变更优先通过更换上表的 canonical 完成；若工具确实只能做变换，只能对完整角色及全部非对称结构做同一整体变换，并在交付前与目标 canonical 并排核对。
- 不接受普通鱼、普通波浪或“看起来像同类对象”的替代角色；方向正确不等于身份正确。

## 双角色比例复核

- 普通同平面双角色场景以小浪花可见高度 ÷ 沙丁可见高度计算：固定目标 `0.392`，验收区间 `0.38–0.42`。
- 可见高度按渲染后角色本身的可见边界测量，不把透明留白或画布尺寸计入。小浪花必须明显小于沙丁；因其轮廓较宽而显得抢重时，继续缩小。
- `50%` 是绝对上限，不是目标；任何超过 `0.50` 的结果必须缩小或重生成后才能交付。透视、动作或遮挡造成的浮动也不能破坏沙丁主角、小浪花配角的层级。
